# Benchmark harness code (not run archives)

This package holds **Python runners/helpers** used by
`MCMC_implementation/scripts/` (e.g. `single_chain_baseline.py`).

Dated experiment outputs and metrics folders belong at the **repo root**:

`benchmarks/`  ← archives only (`YYYYMMDD_.../`, `summary.json`, CSVs)

Do not drop PNGs or HiPerGator result trees here.
